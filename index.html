Why you'll keep it

  • Your usage limits go a lot further. Your assistant reads one page instead of whole files.
  • Answers come with receipts. File and page, so you can open it and check.
  • It won't bluff. If it isn't in your notes, it tells you.
  • Throw anything at it. PDFs (even scans), slides, Word, Excel, Markdown.
  • Set it and forget it. New files get picked up within a minute, and the app updates itself.
  • Watch the savings add up. "Activity" in the tray shows roughly how many tokens it has saved you.

Up and running before your coffee cools

  1. Run the installer. If Windows says it protected your PC, click More info, then Run anyway. Beta builds aren't signed yet.
  2. Pick the folders with your notes and press Start.
  3. Quit Claude Desktop from the tray and open it again. On Claude Code or Codex, start a new session.
  4. Ask: "Using WarpSearch, what did my notes say about <topic>? Cite the page."
