WarpSearch Beta

Your AI assistant answers from your own notes, slides and documents, with the exact file and page, without uploading them and with far fewer tokens. Everything runs on your laptop.

Download for Windows

About 130 MB. Installs for your user only, no admin needed. Updates itself.

Set up in two minutes

  1. Run WarpSearch-Beta-Setup.exe. If Windows warns you, click "More info", then "Run anyway".
  2. Pick the folders with your notes, agree to the beta terms, and press Start.
  3. WarpSearch connects itself to Claude Desktop, Claude Code and Codex if you have them. Restart Claude Desktop fully (quit it from the tray).
  4. Ask your assistant: "Using WarpSearch, what did my notes say about <topic>? Cite the page."

What it does

  • Finds the exact page or slide, and says "not in your notes" instead of guessing.
  • Reads PDF, Word, PowerPoint, Excel, text and Markdown, including scanned pages.
  • Keeps up with new and changed files by itself.
  • The tray menu's "Activity" shows how many tokens it saved your assistant (estimated).

Before you install

This is a test build. It stops working on 21 November 2026 unless a newer update moves the date. While you test, it sends usage data to the developer, including what you ask, file names and text from your notes that it returns to your assistant. To stop, uninstall it.

Read the beta terms and the full README (what is sent, how to delete it).
