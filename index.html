windows, the easy way

Open PowerShell, paste this line and press Enter. It downloads Zarp, checks it against the published checksum and installs it with no clicks and no scary Windows warning. Then Zarp opens and asks which folders to read.

Prefer clicking? Download the .exe instead. Windows will probably say it protected your PC, because beta builds aren’t signed yet (a signing certificate costs money and the beta is free). Click More info, then Run anyway.

mac, the easy way

For Apple Silicon Macs (M1 and newer). Open Terminal, paste this line and press Enter. It checks the download, puts Zarp in Applications and opens it, with no “can’t verify the app” detour.

Prefer clicking? Download the zip and drag Zarp Beta into Applications. The first time, your Mac says it can’t verify the app, because the beta isn’t notarized yet. Open System Settings, then Privacy & Security, scroll down and click Open Anyway. You only do this once.

After installing, quit Claude Desktop and open it again so it sees Zarp. On Claude Code or Codex, start a new session.

Want your data deleted? Open a GitHub issue with your install ID. It’s in beta_settings.json inside %LOCALAPPDATA%\DiskAI-Beta on Windows, or ~/Library/Application Support/DiskAI-Beta on a Mac. Uninstalling stops all sending.
